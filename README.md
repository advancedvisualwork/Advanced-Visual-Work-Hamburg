# 🍔🍕 AVW Lanches

> **Sabor artesanal, ingredientes selecionados e entrega rápida diretamente na sua mesa.**

Bem-vindo ao repositório oficial do projeto digital da **AVW Lanches**! Este projeto tem como objetivo apresentar o cardápio digital, facilitar os pedidos online e destacar a qualidade artesanal dos nossos hambúrgueres e pizzas.

---

## 📋 Sobre o Projeto

A **AVW Lanches** nasceu com a missão de unir o melhor da culinária artesanal — desde hambúrgueres suculentos preparados na chapa até pizzas assadas no ponto certo com bordas levemente tostadas. 

Este sistema/site foi desenvolvido para oferecer uma experiência visual apetitosa, intuitiva e responsiva para nossos clientes realizarem seus pedidos de forma prática.

### ✨ Destaques do Cardápio
* **Hambúrgueres Artesanais:**
  * *Clássico Cheeseburger:* Pão com gergelim, hambúrguer suculento, queijo derretido, alface crocante e tomate fresco.
  * *Bacon Cheeseburger:* Pão tostado, blend bovino, queijo derretido e tiras generosas de bacon crocante.
  * *Crispy Chicken:* Filé de frango empanado super crocante, alface e molho especial cremoso.
  * *Duplo Cheddar & Caramelizada:* Dois hambúrgueres, cheddar cremoso e cebola caramelizada.
* **Pizzas Especiais:**
  * *Margherita:* Molho de tomate artesanal, muçarela fresca, manjericão e borda tostada.
  * *Calabresa:* Calabresa fatiada, cebola roxa em anéis e muçarela derretida.
  * *Frango com Catupiry:* Frango desfiado temperado, cobertura generosa de requeijão cremoso e orégano.
  * *Portuguesa:* Presunto, ovos cozidos, azeitonas pretas, cebola roxa e muçarela.

## 🚀 Funcionalidades

- [x] **Cardápio Digital Interativo:** Visualização de fotos em alta definição, descrição detalhada dos ingredientes e preços.
- [x] **Categorias Organizadas:** Filtros rápidos entre Hambúrgueres, Pizzas, Acompanhamentos e Bebidas.
- [x] **Carrinho de Compras:** Adição, remoção e personalização de itens (adicionais e observações).
- [x] **Checkout Simplificado:** Integração direta para envio de pedidos via WhatsApp ou sistema próprio.
- [x] **Design Responsivo:** Experiência otimizada para dispositivos móveis (smartphones), tablets e desktops.

## 🎨 Identidade Visual & Fotografia

Toda a direção de arte do projeto segue uma estética **Dark & Moody** (fundo preto fosco `#0A0A0A` e ardósia escura), utilizando iluminação lateral suave para realçar a textura, o vapor e o frescor dos ingredientes de cada lanche.

## 💻 Como Executar o Projeto Localmente

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/seu-usuario/avw-lanches.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd avw-lanches
   ```

3. **Instale as dependências** *(caso utilize Node.js/React)*:
   ```bash
   npm install
   ```

4. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```
   *(Ou simplesmente abra o arquivo `index.html` no seu navegador, caso seja um projeto estático).*
